## Лабораторна робота №3: «Адаптивна верстка веб-сторінки з використанням CSS Grid та SCSS»

- **Тема:** Побудова адаптивної сітки на базі CSS Grid Layout та використання розширених можливостей препроцесора SCSS.
- **Мета:** Закріпити навички створення адаптивної верстки веб-сторінок із використанням CSS Grid та медіа-запитів. На прикладі головної сторінки сайту `lpnu.ua` проаналізувати принципи реалізації адаптивного макету та відтворити блок «Новини університету» з елементу `div.main-container`.
- **Реалізація брейкпоінтів:**
  - **Mobile (< 768px):** 1 колонка новин
  - **Tablet (768px – 1023px):** 2 колонки новин
  - **Desktop (&ge; 1024px):** 4 колонки новин
- **SCSS елементи:**
  - Змінні `$primary-color`, `$secondary-color`, `$text-color`, розміри шрифтів.
  - Асоціативний масив `$breakpoints: ( mobile: 576px, tablet: 768px, desktop: 1024px )`.
  - Міксин `@mixin respond-to($breakpoint)`.

### Запуск компіляції SCSS:
```bash
# Встановлення залежностей
npm install

# Одноразова компіляція SCSS у CSS
npm run build:lab3

# Режим автоматичного відстеження змін (Watch Mode)
npm run watch:lab3
```
