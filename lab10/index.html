Створення серверного застосунку на Node.js

Студент: Цвик Віктор | Група: КН-310 (ID #28)

1. Опис серверного застосунку

У цій роботі реалізовано автономний HTTP-сервер на базі вбудованого модуля Node.js http з використанням стандартів сучасних ES-модулів ("type": "module"). Сервер налаштовано для надання REST API даних для Angular та клієнтських веб-застосунків.

  • Event Loop та неблокуюче I/O: асинхронна архітектура обробки клієнтських запитів.
  • CORS політика: додано обов'язкові заголовки Access-Control-Allow-Origin: *, дозволено методи GET, POST, OPTIONS, PUT, DELETE та обробку preflight запитів.
  • Власні модулі: збереження та експорт даних організовано у файлі data.js відповідно до інтерфейсу Todo.

2. Маршрутизація сервера (API Endpoints)

GET / — перевірка працездатності (HTML статус)
GET /api/v1/todoItem — список завдань у форматі JSON
OPTIONS /api/v1/todoItem — обробка попередніх preflight CORS-запитів (HTTP 204)
HTTP 204
